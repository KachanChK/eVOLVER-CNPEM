# Instruções para agentes

### Estas instruções valem para todo o repositório.

## Versionamento
Antes de criar commits ou trabalhar com Git neste projeto, leia [guia_commit.md](guia_commit.md) e siga suas orientações. Isso inclui a escolha da branch, as mensagens de commit, a atualização com o remoto, a resolução de conflitos e o envio das alterações. Consulte a versão atual do guia antes de agir.
