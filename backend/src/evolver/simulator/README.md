# Simulador

Diretório reservado para o futuro processo Python que produzirá dados simulados e
receberá comandos sem efeito físico. Ele poderá importar `evolver.contracts`, mas
não deverá importar `evolver.db` nem `evolver.api`. Nenhum produtor, fila local ou
comando simulado é implementado pela E2-T03.
